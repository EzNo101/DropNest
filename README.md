# DropNest

#### A mini cloud file storage

DropNest is my pet project, built as an excuse to get hands-on practice with two things
I wanted to get comfortable with:

- **S3 buckets** - uploading, downloading, listing and deleting files through AWS S3
  (FastAPI + `aioboto3` on the backend)
- **Frontend development** - a dark, teal-accented UI with Vue 3 + Nuxt 4,
  TypeScript, composables and Tailwind CSS

Both services are containerized with Docker Compose.
